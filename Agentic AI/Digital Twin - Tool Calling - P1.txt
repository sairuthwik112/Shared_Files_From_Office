Messages Structure

Conversation is stored as a list of messages.

Roles:

system = instructions to AI
user = user input
assistant = AI response
tool = output from a tool

Conversation typically looks like: System Prompt → User Message → Assistant Reply → User Message → Assistant Reply

Tool Calling

Normal LLM:

Generates text only

LLM with tools:

Can request external actions

Examples:

Save email
Search web
Query database
Send notification
Call APIs

Important: GPT never executes tools itself.

GPT only says: "Please call this tool."

Python code actually runs the tool.

Email Recording Tool

Purpose:

Save email addresses into emails.txt

Flow: User provides email ↓ GPT identifies email ↓ GPT requests tool execution ↓ Python runs tool ↓ Email saved into file ↓ GPT confirms to user

Why JSON is Used

JSON describes tools in a structured way.

JSON contains:

Tool name
Tool description
Parameters
Required fields

Why JSON?

Standard format
Easy for programs to parse
LLMs are trained on JSON schemas
Eliminates ambiguity
Tool Description Components

Name

Tool identifier

Description

Explains when tool should be used

Parameters

Inputs expected by tool

Required

Mandatory inputs

Example: Tool Name = record_email_tool Parameter = email Type = string

message = response.choices[0].message

tool call requests

When tool calling is used: message.tool_calls becomes important.

Meaning of Tool Arguments

GPT returns arguments as JSON text.

Python uses json.loads() to convert:

JSON String ↓ Python Dictionary

Then extracts values such as email.

Finish Reason

finish_reason tells why GPT stopped.

Common values:

stop

Normal response completed

tool_calls

GPT wants a tool to be executed
Problem with Initial Tool Calling

Initial code assumed:

Only one tool call
Only one email

So it used:

First tool call only

Problem:

User provides:

x@test.com
y@test.com
z@test.com

GPT creates 3 tool calls.

Code handles only first one.

Result: Error

Fix 1: For Loop

Instead of taking only first tool call:

Loop through every tool call.

Benefits:

Supports multiple emails
Supports multiple tool requests
Fix 2: Agent Loop

Original approach:

If GPT requests tool → Execute once

Problem: GPT might need more tools later.

Solution: Replace if with while

Now process continues until GPT no longer requests tools.

Flow:

GPT ↓ Tool Call ↓ Tool Result ↓ GPT ↓ Another Tool Call ↓ Tool Result ↓ GPT Final Answer

Agent Definition

Agent = LLM + Tools + Loop

The loop allows repeated reasoning and actions until task completion.

Why Agent Loop Works

GPT receives goal.

Example:

"Record these three email addresses."

GPT:

Calls tool 1
Calls tool 2
Calls tool 3
Produces final response

The while loop keeps the process running until completion.

Key Interview Answer

What is an AI Agent?

An AI agent is an LLM equipped with tools and running inside a loop so it can repeatedly take actions, observe results, and continue until a goal is achieved.

Formula:

AI Agent = LLM + Tools + Memory/State + Loop

BIG RECAP

There are two main orchestration styles:

Orchestration By Code

Developer controls everything.

Example:

Run Agent A ↓ Run Agent B ↓ Run Agent C ↓ Choose Result

Advantages:

Predictable
Easier debugging
Stable
Production friendly
Orchestration By LLM

LLM controls workflow.

Example:

Manager Agent ↓ Calls Tool 1 ↓ Calls Tool 2 ↓ Calls Tool 3 ↓ Chooses Best Result

Advantages:

More autonomous
More flexible
Better for complex tasks

Disadvantages:

Less predictable
Harder to debug

HANDOFFS VS TOOLS

Tools

Agent A ↓ Calls Tool ↓ Gets Result Back ↓ Continues Working

Control returns to Agent A.

Handoffs

Agent A ↓ Transfers Control ↓ Agent B

Agent B becomes responsible.

Control does not immediately return.

INSTRUCTOR'S RECOMMENDATION

Preferred:

Tools

Reasons:

Simpler
More reliable
Supported everywhere
Easier to understand

Handoffs are OpenAI-specific and use framework-specific behavior.

STEP 1: OPENAI-COMPATIBLE ENDPOINTS

Many providers expose APIs compatible with OpenAI.

Examples:

Google Gemini

OpenRouter

Grok

Because their APIs follow OpenAI format, OpenAI Agents SDK can use them.

OPENAI-COMPATIBLE API

Means:

Even though the model is not OpenAI,

the SDK can communicate with it exactly like an OpenAI model.

Example:

OpenAI SDK ↓ Gemini

OpenAI SDK ↓ Kimi

OpenAI SDK ↓ GPT-OSS

STEP 2: CREATE CLIENTS

A separate client is created for each provider.

Each client contains:

Base URL
API Key

Purpose:

Connect to that model provider.

STEP 3: CREATE MODEL OBJECTS

Unlike OpenAI models,

you do not provide a string.

Instead:

Create a model object.

The model object contains:

Which client to use
Which model name to use

OPENAI MODEL

Example:

Model = "gpt-5.4-mini"

Just text.

NON-OPENAI MODEL

Example:

Model Object

Contains:

Client + Model Name

KEY INTERVIEW TAKEAWAY

OpenAI Agents SDK is not limited to OpenAI models.

You can use:

OpenAI
Gemini
Grok
OpenRouter Models
Open Source Models

by:

Creating a compatible client
Creating a model object
Passing the model object into the Agent

The rest of the agent workflow remains exactly the same.

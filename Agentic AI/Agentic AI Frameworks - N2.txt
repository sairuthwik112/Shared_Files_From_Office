Purpose:

Make agent development easier
What is an Agent Framework?

An agent framework is a helper library that reduces repetitive coding when building agents.

Frameworks do NOT create agents.

They only make development easier and faster.

What Do Frameworks Handle?
1. Orchestration

Connect multiple LLM calls.

Example:

LLM 1 → LLM 2 → LLM 3

2. Tool Calling

Give LLMs abilities like:

Web Search
Database Access
Reading Files
Stock Price Lookup
3. Structured Outputs

Normally:

LLM returns text.

With structured outputs:

LLM returns JSON.

Framework converts JSON into Python objects.

Important:

LLM does NOT create Python objects directly.

LLM → JSON Text → Framework → Python Object

4. MCP Support

MCP lets you use tools built by other people.

Instead of creating every tool yourself, you can connect to existing tools.

5. Agent Loop

Frameworks help create:

LLM ↓ Tool ↓ LLM ↓ Tool ↓ Repeat Until Goal Complete

This is the Agent Loop.

What is an Opinionated Framework?

The framework expects you to follow its way of working.

Advantages
Faster development
Less code
Disadvantages
Less flexibility
Do We Need Frameworks?

No.

You can build agents using:

Python
LLM APIs
Tool Calls
Loops

without any framework.

Why Learn Without Frameworks First?

Anthropic recommends starting without frameworks.

Benefits:

Understand tool calling
Understand loops
Understand how agents really work
Remove framework magic
Framework Selection

Don't overthink framework choice.

Most frameworks ultimately do:

LLM + Tools + Loop + Goal

Choose based on:

Team skills
Simplicity vs flexibility
Personal preference

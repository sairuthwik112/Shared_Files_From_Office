Goal

Build a Deep Research System using 4 specialized agents.

Flow:

User Query
 ↓
 Planner Agent

Why Orchestrate With Code?

Developer controls everything.

Benefits:

Easy to understand
Easy debugging
Predictable workflow
Easy to add guardrails

Pattern:

Runner.run() ↓ Runner.run() ↓ Runner.run()

Function 1: runSearches()

Purpose:

Generate search queries and execute them.

Steps:

Call Planner Agent
Get search plan
Create search tasks
Run all searches in parallel using asyncio.gather()
Return all search results

Flow:

User Query ↓ Planner Agent ↓ 5 Search Queries ↓ AsyncIO Parallel Searches ↓ Results Returned

Why Use AsyncIO.gather()?

Without AsyncIO:

Search 1 ↓ Search 2 ↓ Search 3 ↓ Slow

With AsyncIO:

Search 1

Search 2

Search 3

Search 4

Search 5

(All run together)

↓

Faster execution

Function 2: search()

Purpose:

Perform one web search.

Steps:

Receive search query
Receive search reason
Create input message
Call Search Agent
Return search summary

Flow:

Search Query ↓ Search Agent ↓ Web Search Tool ↓ Summary Returned

Why Include Reason?

Example:

Query: "LangGraph popularity"

Reason: "Need framework adoption data"

The Search Agent gets more context and produces better search results.

Function 3: writeReport()

Purpose:

Convert search results into a report.

Input:

Original query
All search results

Steps:

Call Writer Agent
Generate report
Return ReportData object

Output:

Short Summary
Markdown Report
Follow-up Questions
Function 4: sendReportEmail()

Purpose:

Send final report.

Steps:

Call Email Agent
Convert report to HTML
Use Send Email Tool
Send email

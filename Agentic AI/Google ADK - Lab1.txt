Task 2: Configure MCP Server
What is MCP?

MCP = Model Context Protocol

It is a standard way for agents to access external tools and data.

Think:

Without MCP:

Agent can only chat

With MCP:

Agent can call tools
Agent can access databases
Agent can perform actions

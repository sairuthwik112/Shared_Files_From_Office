Goal: Build, debug, deploy, and use a Paint Agent for Cymbal Shops.

The agent helps users:

Select paint
Select color
Calculate paint quantity
Calculate cost
Use company paint datasheets
Remember previous selections

Task 1: Agent Search

Why?

LLM doesn't know Cymbal Shops paint products.

Need company knowledge source.

Created:

Agent Search App = Paint Search
Data Store = Cymbal Paint
Source = Paint Datasheets PDF

Flow:

User Question ↓ Search App ↓ Datasheet ↓ Correct Product Information

Key Point: Search App provides company-specific knowledge to the agent.

Task 3: Debug Paint Agent

Initial Error:

Multiple tools are supported only when they are all search tools

Reason:

Root Agent had:

Search Tool
Other Tools
Sub-Agent transfers

Google doesn't allow mixing search tools with other tools directly.

Fix:

Find Search Agent.

Search Agent uses VertexAiSearchTool.

Wrap Search Agent using AgentTool.

Remove Search Agent from sub_agents list.

Add Search Agent as tool.

Result:

Agent can search paint data successfully.

Agent Structure

Root Agent

├── Search Agent ├── Room Planner Agent └── Coverage Calculator Agent

Root Agent controls workflow.

Sub-agents perform specialized tasks.

Task 4: Session State

Purpose:

Store customer selections.

Examples:

SELECTED_PAINT

PRICE

COVERAGE_RATE

Fix 1

tools.py

Before:

Tool did nothing.

After:

Stores values inside:

tool_context.state

Example:

SELECTED_PAINT = EcoGreens

PRICE = 45

COVERAGE_RATE = 12

Fix 2

Coverage Calculator Agent

Before:

COVERAGE_RATE

PRICE

were treated as plain text.

Agent couldn't read saved values.

Replace With:

{COVERAGE_RATE?}

{PRICE?}

Meaning:

Read value from session state.

? means optional.

No crash if value doesn't exist.

Session State Flow

User selects paint ↓ Store in state ↓ Coverage Agent reads state ↓ Calculate liters ↓ Calculate buckets ↓ Calculate cost

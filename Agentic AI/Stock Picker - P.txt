Project Goal

Build a CrewAI application that:

Finds trending companies in a sector
Researches those companies
Chooses the best company for investment
Sends a notification with the recommendation
New Concepts Learned
1. Tools

Tool = Capability given to an agent

Examples:

SERPA Search Tool
Push Notification Tool

Without tools → Agent only uses LLM knowledge

With tools → Agent can search web, call APIs, send notifications, etc.

2. Structured Outputs

Instead of free-text output, force LLM to generate structured data.

CrewAI uses:

Pydantic Models

Benefits:

Consistent format
JSON output
Easier processing
3. Context

Context = Output from one task passed to another task.

Example:

Find Trending Companies

↓

Research Companies

↓

Pick Best Company

Each task uses previous task results.

4. Memory

Enable using:

memory=True

Purpose:

Remember previous runs
Avoid repeating results
Store important information

CrewAI automatically performs memory retrieval.

Memory works similar to built-in RAG.

5. Hierarchical Process

Manager Agent controls workflow.

Instead of:

Task1 → Task2 → Task3

LLM Manager decides:

What runs first
What runs next
Task delegation

How Structured Outputs Are Added

Step 1:

Create Pydantic Model

Step 2:

Use

inside task definition

That's all.

CrewAI automatically generates structured JSON.

Sequential vs Hierarchical

Sequential

Fixed order
Code decides workflow

Example:

Task1 → Task2 → Task3

Hierarchical

Manager Agent decides workflow
LLM controls execution

Example:

Manager ↓ Task Selection ↓ Agent Execution

allow_delegation=True

Add to Crew

Important Lessons

✅ Tools extend agent capabilities

✅ Pydantic enables structured outputs

✅ Context passes outputs between tasks

✅ Memory adds retrieval functionality

✅ Hierarchical process uses manager agent

✅ Traces help debug workflows

✅ CrewAI provides many features out of the box

Interview Revision

Tool = External capability available to agent

Context = Previous task output used by another task

Memory = Retrieval of information from previous runs

Structured Output = LLM output constrained using Pydantic

Sequential = Fixed workflow

Hierarchical = Manager-controlled workflow

Manager Agent = Delegates and coordinates tasks

output_pydantic = Creates structured JSON response

@tool = Converts Python function into CrewAI Tool

memory=True = Enables Crew memory

Biggest Takeaway

CrewAI makes advanced agent features extremely easy:

Tools → add with tools=[...]
Structured Outputs → output_pydantic=
Memory → memory=True
Hierarchical Workflow → Process.hierarchical
Custom Tools → @tool

A few configuration changes can turn a simple agent into a multi-agent system with tools, memory, structured outputs, and manager-based orchestration.

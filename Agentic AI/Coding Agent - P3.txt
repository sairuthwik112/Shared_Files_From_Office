How Docker Execution Works

Tool runs:

Docker Container

↓

Mount sandbox folder

↓

Execute Python file

↓

Capture output

↓

Destroy container

Container is temporary.

Called:

Ephemeral Container

Meaning:

Exists briefly and gets removed.

Docker Command Logic

Container:

Python 3.13

Sandbox Folder:

Mounted inside container

Python File:

Executed

Output:

Captured and returned to agent

Timeout:

60 seconds

If longer:

Fail execution

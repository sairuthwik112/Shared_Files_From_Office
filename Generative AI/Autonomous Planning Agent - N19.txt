Step 2: Refresher On Tool Calling

LLMs cannot execute functions directly.

Instead:

Example:

Tool 3:

Step 5: Tool JSON

Every tool needs a JSON description.

Example:

Tool Name
Description
Parameters


Example:

{
  "name": "estimate_true_value",
  "description": "Estimate product value"
}


This JSON tells GPT:

What tools exist
What each tool does
What arguments are required

Step 6: Important Observation

The LLM never sees Python functions.

The LLM only sees:

Tool Schema


Example:

{
 "name":"scan_internet"
}


The model knows:

A tool exists


It doesn't know how the function is implemented.

Biggest Learning From This Lesson

The Planning Agent itself does not know how to:

Scan RSS Feeds
Predict Product Values
Send Notifications

It only knows:

Which tool should I call next?


This is exactly how agentic systems work.

The Planning Agent is the "manager."

The other agents are the "specialists."

The manager breaks the problem into steps, calls specialists when needed, receives results, and keeps looping until the goal is achieved.

That is why the instructor says the core definition of an Agent is:

LLM
+
Tools
+
Loop
+
Goal
=
Agentic AI System

What is an Ensemble Model?

An ensemble model combines predictions from multiple models to produce a final prediction.

Instead of relying on one model, it uses the strengths of several models.

In this project, the ensemble combines:

Specialist Agent (Fine-Tuned LLM)
Frontier Agent (RAG + Frontier Model)
Neural Network Agent

The goal is to reduce prediction error and increase accuracy.

MODELS USED

Specialist Agent

Uses the fine-tuned model deployed on Modal.

Job:

Receives product description
Sends it to fine-tuned model
Returns predicted price
Frontier Agent

Uses RAG.

Process:

Find similar products from ChromaDB
Retrieve relevant chunks
Build prompt with context
Send prompt to GPT-5.1
Get price prediction

This became one of the strongest models.

Neural Network Agent

Uses a deep neural network.

Process:

Product description
Feature extraction
Neural network inference
Predicted price

ENSEMBLE FORMULA

The ensemble combines predictions using weights.

Frontier Agent = 80%

Specialist Agent = 10%

Neural Network Agent = 10%

Final Prediction:

80% Frontier Price + 10% Specialist Price + 10% Neural Network Price

The Frontier Agent received the largest weight because it had the best performance.

WHY ENSEMBLE WORKS

Different models make different mistakes.

Example:

XGBoost: $820

DNN: $880

LLM: $860

Actual: $850

Combining them can produce a value closer to the true price.

The ensemble benefits from multiple perspectives.

IMPORTANT OBSERVATION

Ensemble is not always the winner.

Example:

Shure MV7+ Microphone

Actual Price: $299

Specialist Model: $299 (perfect)

Frontier Model: $289

Ensemble: Slightly worse

This shows that for individual products, one model may outperform the ensemble.

However, across many products the ensemble usually performs better overall.

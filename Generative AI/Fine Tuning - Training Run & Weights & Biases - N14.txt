Understanding Training Loss
What is Training Loss?
Measures:
How wrong model predictions are on training data.

Desired Trend
Training Loss:
3.0
↓
2.0
↓
1.5
↓
1.2
Good ✅

Why Big Drop Happens Initially
Model quickly learns output format.
Example:
Price data:
Learns:

answer contains number
answer contains decimal
answer ends correctly

This rapidly reduces loss.

Training Loss Curve
Typical pattern:

↓
Gradual improvement
↓

This is normal.

Every batch is different.
Example:
Batch 1

Batch 2

Loss fluctuates naturally.

Validation Loss (Most Important)
What is Validation Loss?
Loss measured on unseen validation data.
Validation data is:

never used for learning
only used for evaluation


Why Validation Loss Matters
Training loss can improve because:

model memorizes training data

Validation loss shows:

actual generalization


Desired Validation Loss Trend
Validation Loss:
1.30
↓
1.28
↓
1.26
↓
1.24
Good ✅
Model improving on unseen data.

Why Validation Loss Is Better Than Training Loss
Training Loss:

different batches every time

Validation Loss:

same validation dataset every time

Therefore:

more reliable
less noisy


Evaluation Frequency
Validation performed:
Every save step
Example:
Save every 100 steps
Then:
Step 100
→ Validation
Step 200
→ Validation
Step 300
→ Validation

Interpreting Results
Good Training
Training Loss ↓
Validation Loss ↓
Meaning:

learning
generalizing

Perfect ✅

Overfitting
Training Loss ↓
Validation Loss ↑
Meaning:

memorization
poor generalization

Bad ❌

Example From The Run
Initial Eval Loss:

Later Eval Loss:
1.24
Meaning:

validation performance improved
fine-tuning worked

Important Concepts Learned
Training Loss
Error on training data.

Validation Loss
Error on unseen validation data.

Warmup
Gradually increases learning rate at start.

Cosine Scheduler
Gradually decreases learning rate later.

Checkpoint
Saved version of model during training.

Evaluation
Testing model on validation data during training.

Generalization
Model performs well on unseen data.

Overfitting
Model memorizes training data and performs poorly on unseen data.

Interview Notes

Training loss should decrease during training.
Validation loss is more important than training loss.
Validation loss measures performance on unseen data.
Warmup slowly increases learning rate at beginning.
Cosine scheduler gradually decreases learning rate.
Checkpoints are saved periodically during training.
SFT Trainer automates fine-tuning.
A good model has both training loss and validation loss decreasing.
Overfitting occurs when training loss decreases but validation loss increases.
Validation loss is the primary metric for selecting the best checkpoint.

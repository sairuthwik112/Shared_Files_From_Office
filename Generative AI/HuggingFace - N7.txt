-> Pipelines for inference tasks

Inference is like running the model that is already trained with the data

The most commonly used Hugging Face pipelines include text-generation, sentiment-analysis, question-answering, summarization, and feature-extraction, which are widely used in building AI applications like chatbots, RAG systems, and document processing tools.

Hugging Face pipelines use predefined default models for each task based on internal mappings. They do not dynamically select the best model, so developers can override the default by specifying a model explicitly.

Transformers are neural network architectures used in LLMs to process and generate text using attention mechanisms, while diffusion models are used for image generation by starting from noise and iteratively refining it into a coherent image.

-> Quantization

Quantization is a technique that reduces the precision of model weights (e.g., from 32-bit to 8-bit or 4-bit) to decrease memory usage and improve inference speed, enabling efficient deployment of large models on limited hardware.

-> Tokenizer

In Hugging Face, tokenizers convert text into model-readable tokens, and different models use different tokenization methods like BPE, WordPiece, or SentencePiece. For chat models, apply_chat_template formats conversation messages, and add_generation_prompt ensures the model generates a response.

-> HuggingFace Transformers

Model parameters consist of multiple types of weights, including embedding weights, attention weights (query, key, value), feedforward network weights, and output projection weights, all of which work together to process input and generate predictions.

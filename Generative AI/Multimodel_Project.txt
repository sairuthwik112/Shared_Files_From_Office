Why do we need to use tools in the pre trained models

Because the model can trained and gives the predictive answer not the exact answer 

so when we trained the models with tools we can get the exact answers

User asks price
        ↓
Model realizes it needs real data
        ↓
Calls get_ticket_price("Paris")
        ↓
Database returns $500
        ↓
Model responds with actual value

User:
Price to Paris?
        ↓

Model:
I need database access
        ↓

Tool Call:
get_ticket_price("Paris")
        ↓

Database:
$500
        ↓

Tool Result Returned
        ↓

Model Called Again
        ↓

Final Answer:
"The ticket price to Paris is $500."



Process






Example Input

User asks:

What is the ticket price to Paris?
Execution Flow (Point-by-Point)
1. chat(history) is called
Receives conversation history from Gradio.
History contains the user's latest message.
2. Convert history format
history = [{"role":h["role"], "content":h["content"]} for h in history]
Converts history into OpenAI-compatible format.
Example:
User → "What is the ticket price to Paris?"
3. Create messages
messages = [{"role": "system", "content": system_message}] + history
Adds system prompt.
Adds conversation history.
Final messages:
System message
User message
4. First LLM Call
response = client.chat.completions.create(...)
Sends messages and available tools to the model.
Model receives:
User question
Tool descriptions
5. Model decides a tool is needed
User asked for ticket price.
Model cannot access database directly.
Model chooses:
get_ticket_price(destination_city="Paris")
6. Model returns Tool Call

Instead of an answer, model returns:

{
  "name": "get_ticket_price",
  "arguments": {
      "destination_city": "Paris"
  }
}
finish_reason = "tool_calls"
7. Enter While Loop
while finish_reason == "tool_calls":
Since model requested a tool, loop starts.
8. Extract Tool Request
message = response.choices[0].message
Contains:
Tool name
Arguments
Tool call ID
9. Call handle_tool_calls_and_return_cities()
responses, cities = handle_tool_calls_and_return_cities(message)
Inside handle_tool_calls_and_return_cities()
10. Create empty lists
responses = []
cities = []
11. Loop through tool calls
for tool_call in message.tool_calls:
Reads each requested tool.
12. Check tool name
if tool_call.function.name == "get_ticket_price":
Confirms requested tool.
13. Read arguments
arguments = json.loads(tool_call.function.arguments)

Converts:

'{"destination_city":"Paris"}'

to

{
  "destination_city":"Paris"
}
14. Extract city
city = arguments.get("destination_city")

Result:

city = "Paris"
15. Save city
cities.append(city)

Result:

cities = ["Paris"]

Purpose:

Used later for image generation.
16. Query Database
price_details = get_ticket_price(city)

Calls:

get_ticket_price("Paris")

Database returns:

"Ticket price to Paris is $500"
17. Create Tool Response
responses.append(...)

Creates:

{
    "role":"tool",
    "content":"Ticket price to Paris is $500",
    "tool_call_id":"call_001"
}
18. Return Values
return responses, cities

Returns:

responses = [...]
cities = ["Paris"]
Back to chat()
19. Save Assistant Tool Request
messages.append(message)

Adds model's tool request to conversation history.

20. Save Tool Result
messages.extend(responses)

Adds database result to conversation history.

21. Second LLM Call
response = openai.chat.completions.create(...)

Model now sees:

User question
Tool request
Tool result
22. Generate Final Answer

Model creates:

The ticket price to Paris is $500.
23. Exit While Loop
finish_reason = "stop"
Loop ends.
24. Extract Reply
reply = response.choices[0].message.content

Result:

"The ticket price to Paris is $500."
25. Update History
history += [{"role":"assistant","content":reply}]

Conversation now contains:

User message
Assistant reply
26. Generate Voice
voice = talker(reply)

Input:

The ticket price to Paris is $500.

Output:

Audio file / speech
27. Generate Image
if cities:
    image = artist(cities[0])

Uses:

artist("Paris")

Output:

Image of Paris
28. Return Everything
return history, voice, image

Returns:

Updated chat history
Audio response
Generated city image

Overfitting happens when a model memorizes the training data instead of learning the patterns.

-> Hyperparameters for fine tuning

Batch
A batch is a small group of training examples processed at one time.
Example:
1000 training examples
Batch size = 100

The model learns from:
100 examples → update weights
Next 100 examples → update weights

✅ Saves memory

Epoch
An epoch means the model has seen the entire dataset once.
Example:
1000 examples
Batch size = 100

After processing all 10 batches:
100 + 100 + ... + 100 = 1000

✅ 1 Epoch completed

Why Multiple Epochs?
Just like a student reads a book multiple times.
Epoch 1 → Learn basics
Epoch 2 → Learn better
Epoch 3 → Learn even better

Too many epochs:
❌ Model may memorize data (overfitting)

Simple Memory Trick
Batch = Few pages of a book

Epoch = Reading the whole book once

Example:
Dataset = 1000 samples
Batch Size = 100
Epochs = 3

Result:
10 batches = 1 epoch

10 batches × 3 epochs
= 30 training steps

Batch = How much data to learn at a time
Epoch = How many times to read the entire dataset 

Learning Rate 

Learning Rate = How much the model changes its knowledge after seeing a mistake.
Example:
Actual answer = 10
Model predicted = 6
The model made a mistake.
Gradient says:
"Increase the weight."
Learning rate decides:
"How much should I increase it?"
Small learning rate:

Small weight changes
Learns slowly
More stable

Large learning rate:

Big weight changes
Learns faster
Can become unstable

Simple analogy:
Gradient = Direction
Learning Rate = Step size
If someone says:
"Go east."
That is the gradient.
Take 1 step east = Small learning rate
Take 100 steps east = Large learning rate
Interview answer:
Learning Rate is a hyperparameter that controls how much the model's weights are updated during each training step. A small learning rate learns slowly, while a large learning rate learns faster but may become unstable. ✅Provide your feedback on BizChatFilesFiles

Gradient Accumulation
Gradient accumulation is used when your GPU cannot handle a large batch size.
Example:
You want:

Batch Size = 16

But GPU can only fit:

Batch Size = 4

So instead of updating weights after every 4 samples:
Step 1:

Process 4 samples
Save gradients

Step 2:

Process next 4 samples
Add gradients

Step 3:

Process next 4 samples
Add gradients

Step 4:

Process next 4 samples
Add gradients

Now:
4 + 4 + 4 + 4 = 16 samples
Then update weights once.
Why use it?

Uses less GPU memory
Simulates a larger batch size
Helps train large models on smaller GPUs

Simple memory trick:

Batch Size = Data processed at once
Gradient Accumulation = Number of batches to combine before updating weights


Optimizer
Optimizer is the component that updates the weights using gradients.
Flow:
Training Data
↓
Prediction
↓
Loss
↓
Gradient
↓
Optimizer updates weights
Think of it like:

Gradient tells the model what direction to move.
Optimizer decides how to move the weights.

Example:
Suppose:

Weight = 100
Gradient = 2
Learning Rate = 0.1

Optimizer calculates:
New Weight = 100 - (0.1 × 2)
= 99.8
The optimizer performs this update.

Common Optimizers
SGD (Stochastic Gradient Descent)

Basic optimizer
Moves using gradients directly
Simple but slower

Adam

Most popular
Learns faster
More stable

AdamW

Most commonly used for LLM fine-tuning
Improved version of Adam
Used in QLoRA and Hugging Face training

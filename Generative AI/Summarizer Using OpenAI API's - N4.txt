This code builds a simple AI application where you give a website URL, the program fetches its content, prepares prompts (system + user), and sends the data to an LLM. The model reads the content and generates a summary, which is then returned and displayed in a clean format.

# Install required libraries (if needed)
# pip install openai python-dotenv requests beautifulsoup4

from openai import OpenAI
from dotenv import load_dotenv
import os
import requests
from bs4 import BeautifulSoup
from IPython.display import display, Markdown

# -------------------------------
# STEP 1: Load API key
# -------------------------------
load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")

if not api_key:
    print("No API key found!")
else:
    print("API key loaded successfully")

# -------------------------------
# STEP 2: Initialize OpenAI client
# -------------------------------
client = OpenAI()

# -------------------------------
# STEP 3: Test simple LLM call
# -------------------------------
message = "Hello GPT! This is my first message"

messages = [
    {"role": "user", "content": message}
]

response = client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages
)

print("Test Response:")
print(response.choices[0].message.content)

# -------------------------------
# STEP 4: Fetch website content
# -------------------------------
def fetch_website_contents(url):
    response = requests.get(url)
    soup = BeautifulSoup(response.text, "html.parser")
    return soup.get_text()

# -------------------------------
# STEP 5: Define prompts
# -------------------------------
system_prompt = """
You are a helpful assistant that summarizes website content.
Provide a short and clear summary.
"""

user_prompt_prefix = """
Here is the content of a website:
"""

# -------------------------------
# STEP 6: Create messages function
# -------------------------------
def messages_for(website):
    return [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_prompt_prefix + website}
    ]

# -------------------------------
# STEP 7: Main summarize function
# -------------------------------
def summarize(url):
    website = fetch_website_contents(url)

    response = client.chat.completions.create(
        model="gpt-4.1-mini",
        messages=messages_for(website)
    )

    return response.choices[0].message.content

# -------------------------------
# STEP 8: Display nicely
# -------------------------------
def display_summary(url):
    summary = summarize(url)
    display(Markdown(summary))

# -------------------------------
# STEP 9: Run the project
# -------------------------------
display_summary("https://edwarddonner.com")



Difference Between Open and Closed Source Models

Open Source Models

Code is available
Weights are available (fully or partially)
Can run locally
Can modify and fine-tune
Free to use
High privacy (data stays on your system)
Performance is good but not top-level

✅ Examples:

Llama 2 / Llama 3
Mistral / Mixtral
Gemma
Falcon
GPT‑2


🔒 Closed Source Models

Code is not available
Weights are not accessible
Only usable through API
Cannot modify the model
Paid (API cost)
Data goes to cloud
Very high performance

✅ Examples:

GPT‑4 / GPT‑5 (OpenAI)
Claude (Anthropic)
Gemini (Google)

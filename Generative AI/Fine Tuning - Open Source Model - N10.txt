✅ ✅ WEIGHTS – NOTES
✅ What are Weights


Weights are numbers inside the model


Stored as:

vectors ✅
matrices ✅



Example:


W = [[0.2, -0.5, 0.8], ...]


✅ What Do Weights Do

Control importance of input ✅
Transform embeddings ✅
Learn patterns from data ✅


✅ Simple Formula
Output = Input × Weight + Bias


✅ In LLM (GPT / LLaMA)
Weights exist in:

Attention layers → Wq, Wk, Wv ✅
MLP layers ✅
Embedding layer ✅


✅ Size of Weights

Millions / billions of numbers
Example:

3B parameters = 3 billion numbers


✅ Important Point
👉 Weights are:

randomly initialized first ❌
learned during training ✅


✅ ✅ HOW WEIGHTS WORK (IN NORMAL MODEL)
✅ Flow
Text → Tokens → Embeddings → Multiply with weights → Output


✅ What Happens

Input → converted to embeddings ✅
Embeddings × weights ✅
Transformed into new vectors ✅
Repeated across layers ✅


✅ Key Idea
👉 Weights do NOT store data
👉 They store patterns

✅ ✅ HOW WEIGHTS ARE LEARNED
✅ Training Process
1. Give input
2. Model predicts
3. Calculate error
4. Update weights
5. Repeat


✅ Update Formula
New Weight = Old Weight - learning_rate × gradient


✅ Important Insight
👉 Data → teaches
👉 Weights → learn

✅ ✅ WEIGHTS IN ATTENTION (IMPORTANT 🔥)
✅ QKV Calculation
Q = Embedding × Wq
K = Embedding × Wk
V = Embedding × Wv


✅ Meaning

Wq → helps ask questions
Wk → helps match words
Wv → holds information


✅ Important
👉 Same weights are used for:

all tokens ✅
every input ✅


✅ ✅ WEIGHTS IN FINE-TUNING (MAIN PART 🔥)

✅ Case 1: Full Fine-Tuning

Update all weights ❌ (expensive)

Wq, Wk, Wv, MLP → ALL updated


✅ Case 2: LoRA Fine-Tuning ✅ (Most Important)
✅ What Happens
1. Load pretrained model
2. Freeze all weights ❌ (no updates)
3. Add LoRA parameters (small matrices)


✅ LoRA Weights
A and B matrices


✅ Final Weight Formula
New Weight = Original Weight + α × (A × B)


✅ Training Step
👉 During fine-tuning:

❌ Original weights NOT updated
✅ Only LoRA weights updated


✅ Flow in Fine-Tuning
Input → Model → Prediction
↓
Calculate loss
↓
Backpropagation
↓
Update LoRA weights only


✅ ✅ KEY DIFFERENCE

ConceptNormal TrainingFine-Tuning (LoRA)Weights updatedAllOnly fewCostHighLowSpeedSlowFast

✅ ✅ FINAL KEY POINTS 🔥

Weights = numbers inside model
They transform embeddings
They are learned from data
In fine-tuning:

base weights are frozen ✅
small weights are added and trained ✅




✅ ✅ ONE-LINE SUMMARY
👉 Weights are numerical parameters that transform embeddings, and in fine-tuning (LoRA), only small additional weights are updated instead of the full model.

Base Model
A base model is the original pretrained model that has learned language from huge amounts of internet, books, articles, etc.
Examples:

Llama 3 Base
GPT Base
Mistral Base

Its job:

Predict the next token.
Complete text.
Doesn't know how to behave as an assistant.

Example:
Prompt:
What is Python?

Base model output:
What is Python?

Python is a programming language created by Guido van Rossum...

Or it may continue the text in unexpected ways because it is simply doing next-token prediction.
Chat Model
A chat model starts with a base model and is then instruction-tuned.
Process:
Base Model
     ↓
Instruction Tuning
     ↓
Chat Model

During instruction tuning, the model learns:

Follow instructions
Answer questions
Refuse harmful requests
Maintain conversations
Act like an assistant

Examples:

GPT-4o Chat
ChatGPT models
Llama 3 Instruct
Mistral Instruct

Example:
Prompt:
What is Python?

Chat Model output:
Python is a high-level programming language commonly used for web development, data science, AI, and automation.

It gives a direct helpful answer because it was trained to follow instructions.
